# SmokeFinder3000
> [!WARNING]
> Using this on official VAC-secured servers will result in a ban. Use at your own risk, preferably in `-insecure` mode.

An internal overlay for finding smoke lineups using Bayesian mathematics in Counter-Strike 2. 
The project is designed as a training, experimentation, and research tool for offline play. It does not provide gameplay assistance in live matchmaking.

> **Status:** Not finished.
